# Estudiantes App

Aplicacion Flask + MySQL para consultar, editar y eliminar estudiantes.

## Ejecucion

```powershell
pipenv install
pipenv run python server.py
```

Abrir: `http://127.0.0.1:5000/estudiantes`

La conexion usa MySQL con `root` y contrasena `1234`. Ajusta `mysqlconnection.py` si tus credenciales son diferentes.
